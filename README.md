## Development

Use Bun 1.4.2 as the package manager.

```sh
bun install --frozen-lockfile
bun run dev
```

## Commands

```sh
bun run build
bun run start
bun run format
bun run format:check
```

Commit `bun.lock` when dependencies change. Use `bun add <package>` and
`bun remove <package>` to manage dependencies.
